# TTRPG Idea
### Game Concept

The basic idea that I'm running with is more of a resource based system, less of a luck based one.
My intent is for the Arcane Arts to be relatively open to experimentation with some signpost abilities, and for the same to be true of the Martial Arts.
Having a few key resource pools for each class type, and different ways to interact with those resource pools seems like a solid way to do things.
Planning on using the 3 action economy of Pathfinder 2nd edition and Slay the Spire.
Possible deck of cards for the RNG element?
Don't want to have TOO many different elements.
Explore the idea of combat taking place on a flower-shaped Hex Grid, with multiple units capable of being on the same tile, and the grid representing an area of combat as opposed to a 5-foot square.
